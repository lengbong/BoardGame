우리 가족 보드게임
==================

[실행 방법]
1. 이 폴더의 index.html 파일을 더블클릭하세요.
2. 크롬, 엣지, 웨일, 파이어폭스 같은 브라우저에서 바로 열려요.
3. 인터넷 연결 없이도 실행돼요.

[게임 방법]
- 처음 화면에서 하고 싶은 게임을 고르세요. (모두 17가지)
  말판·주사위: 말판 경주, 지구 한 바퀴
  카드·타일: 한 장 남았다!, 숫자 타일 줄세우기, 짝 맞추기, 도둑잡기, 칠 이어놓기, 도미노, 거짓말쟁이
  둘이서 수 싸움: 뒤집기, 사목, 만칼라
  실시간 퍼즐: 말랑 팡팡 (혼자 / 컴퓨터와 / 둘이서 한 키보드)
  종이·연필 놀이: 점과 상자, 배 찾기, 숫자야구
  혼자 푸는 퍼즐: 스도쿠 (문제지 인쇄 가능)
- 자리마다 사람 / 컴퓨터를 고르고 "게임 시작"을 누르세요.
- 주사위: 버튼 클릭 또는 Space 키
- 말 고르기: 반짝이는 말을 클릭하거나 숫자키 1~4
- 한 장 남았다!: 반짝이는 카드를 클릭, 뽑기는 Space 키, 카드가 2장이면 "한 장!" 버튼
- 숫자 타일 줄세우기: 타일을 눌러 고르고 줄 끝의 ＋나 "새 줄 만들기"를 누른 뒤 "완료"(Enter)
- 짝 맞추기: 카드 클릭 또는 화살표 키로 고르고 Enter/Space로 뒤집기
- 도둑잡기: 다음 사람 카드를 클릭해서 뽑기(←→ 고르고 Space), S 키로 내 카드 섞기
- 칠 이어놓기: 반짝이는 카드나 판의 빈칸을 클릭(←→ 고르고 Enter), 낼 카드가 없으면 Space로 통과
- 도미노: 반짝이는 패를 클릭(또는 ←/→·숫자키 후 Enter), 두 끝에 다 맞으면 ←/→로 끝 고르기, 뽑기는 D, 통과는 Space
- 거짓말쟁이: 카드를 눌러 1~4장 고르고 Enter로 내기(A 지금 숫자 모두 고르기), 거짓말! D, 믿어요 Space
- 뒤집기: 칸을 클릭하거나 방향키로 고르고 Enter, 무르기는 U
- 사목: 줄을 클릭하거나 숫자키 1~7 (←→로 고르고 Enter), 무르기는 U
- 만칼라: 반짝이는 내 구멍 클릭 또는 숫자키 1~6 (←→로 고르고 Enter), 무르기 U, 도움말 H
- 말랑 팡팡: ←→ 움직이기, ↑·X / Z 돌리기, ↓ 빨리, Space 바로 떨어뜨리기, P 멈추기
  (둘이서: 왼쪽 A·D·W·Q·S·Space, 오른쪽 방향키·/·Enter)
- 점과 상자: 점 사이를 클릭하거나 화살표 키로 선을 고르고 Enter(Space)로 긋기
- 배 찾기: 배는 끌어다 놓거나 눌러서 놓기, R(또는 오른쪽 클릭)로 돌리기 · 쏠 칸은 클릭 또는 방향키 + Enter
- 숫자야구: 숫자 단추나 키보드 숫자로 넣고 Enter로 치기, 지우기 Backspace, 메모 Shift+숫자
- 스도쿠: 칸을 클릭하거나 화살표로 고르고 숫자 1~9, 지우기 Backspace, 메모 N, 힌트 H, 되돌리기 Ctrl+Z
  문제지 인쇄는 스도쿠 설정 화면의 '문제지 만들기' (인쇄 창에서 용지 A4, 배율 100%)
- 하던 게임은 자동 저장돼서 창을 닫았다 열어도 이어서 할 수 있어요.
  (같은 브라우저, 같은 폴더 위치에서 열었을 때)
