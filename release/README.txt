우리 가족 보드게임
==================

[실행 방법]
1. 이 폴더의 index.html 파일을 더블클릭하세요.
2. 크롬, 엣지, 웨일, 파이어폭스 같은 브라우저에서 바로 열려요.
3. 인터넷 연결 없이도 실행돼요.

[게임 방법]
- 처음 화면에서 하고 싶은 게임(말판 경주, 지구 한 바퀴, 한 장 남았다!)을 고르세요.
- 자리마다 사람 / 컴퓨터(쉬움·보통) / 비움을 고르고 "게임 시작"을 누르세요.
- 주사위: 버튼 클릭 또는 Space 키
- 말 고르기: 반짝이는 말을 클릭하거나 숫자키 1~4
- 한 장 남았다!: 반짝이는 카드를 클릭, 뽑기는 Space 키, 카드가 2장이면 "한 장!" 버튼
- 하던 게임은 자동 저장돼서 창을 닫았다 열어도 이어서 할 수 있어요.
  (같은 브라우저, 같은 폴더 위치에서 열었을 때)
