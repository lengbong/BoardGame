# 우리 가족 보드게임 🎲

가족이 **한 대의 PC 브라우저**에 둘러앉아 함께 하는 보드게임 모음입니다. (18가지)
사람이 모자라면 컴퓨터가 빈 자리를 채워 줍니다. 서버나 인터넷 연결 없이 동작합니다.

## 바로 하기

| 방법 | 주소 |
| --- | --- |
| 🌐 설치 없이 웹에서 하기 | https://lengbong.github.io/BoardGame/ |
| 💾 내려받아서 하기 | [family-boardgame.zip 다운로드](https://github.com/lengbong/BoardGame/releases/latest/download/family-boardgame.zip) |

내려받은 경우: 압축을 풀고 `family-boardgame/index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다.

## 게임 목록

| 분류 | 게임 | 인원 |
| --- | --- | --- |
| 🎲 말판·주사위 | 말판 경주, 지구 한 바퀴 | 2~4명 |
| 🃏 카드·타일 | 한 장 남았다!, 숫자 타일 줄세우기, 짝 맞추기, 도둑잡기, 칠 이어놓기, 도미노, 거짓말쟁이 | 2~4명 |
| ♟️ 둘이서 수 싸움 | 뒤집기, 사목, 만칼라, 오목 | 2명 |
| 🕹️ 실시간 퍼즐 | 말랑 팡팡 (혼자 / 컴퓨터와 / 둘이서 한 키보드) | 1~2명 |
| ✏️ 종이·연필 놀이 | 점과 상자 (2~4명), 배 찾기 (2명), 숫자야구 (1~2명) | 1~4명 |
| 🧩 혼자 푸는 퍼즐 | 스도쿠 (문제지 인쇄 가능) | 1명 |

모든 게임 공통:

- 자리마다 **사람 / 컴퓨터** 선택: 2~4명 게임은 사람 / 컴퓨터(쉬움·보통) / 비움, 2명 게임은 사람 / 컴퓨터(쉬움·보통·어려움). 컴퓨터끼리 두는 것을 구경할 수도 있음
- 하던 게임은 자동 저장되어 새로고침해도 이어서 할 수 있음. 처음 화면 맨 위의 **하던 게임 이어하기**와 카드의 '하던 게임' 표시로 바로 찾을 수 있음
- 컴퓨터와 겨룬 **전적**(승·패·무승부)이 게임마다 쌓여 처음 화면 카드에 '🏆 3승 1패'처럼 보임
- 게임을 처음 열면 그림 3장짜리 **이렇게 해요** 안내가 나오고, 화면 오른쪽 아래 ❓로 다시 볼 수 있음
- 주소 끝에 `#/게임`이 붙어서 브라우저·휴대폰의 뒤로 가기로 게임 목록에 돌아오고, 새로고침해도 그 게임 화면에 남음
- 그림·카드·판은 모두 직접 그린 SVG, 배경음악은 게임마다 직접 작곡한 곡을 WebAudio로 합성 (음악·효과음 따로 켜고 끄기)
- 서로 숨겨야 하는 게임은 사람이 2명 이상이면 차례마다 **차례 넘김 화면**으로 가리고, 배울 때는 **모두 공개**로 할 수 있음
- 색마다 모양을 함께 써서 색을 구별하기 어려워도 할 수 있고, 다크 모드와 키보드 조작을 지원

### 말판 경주 (2~4명)

주사위를 굴려 내 말 4개를 먼저 가운데 골인 지점까지 보내면 이기는 경주 게임입니다.

- 자리마다 **사람 / 컴퓨터(쉬움·보통) / 비움** 선택
- 상대 말이 있는 칸에 도착하면 잡아서 대기실로 돌려보내기
- 조작: 주사위는 버튼 클릭 또는 `Space`, 말은 클릭 또는 숫자키 `1`~`4`
- 하던 게임은 자동 저장되어 새로고침해도 이어서 할 수 있음
- 규칙은 게임 시작 전에 켜고 끌 수 있음 (정통 규칙 / 쉬운 규칙 프리셋 제공)

| 규칙 | 정통 | 쉬운 |
| --- | :---: | :---: |
| 6이 나와야 출발 | ✅ | ❌ |
| 6이 나오면 한 번 더 | ✅ | ✅ |
| 6이 세 번 연속이면 차례 끝 | ✅ | ❌ |
| 잡거나 골인하면 한 번 더 | ✅ | ✅ |
| 안전칸(★)에서는 잡히지 않음 | ✅ | ✅ |
| 정확한 수로만 골인 | ✅ | ❌ |
| 1등이 나오면 끝 | ❌ | ❌ |

### 지구 한 바퀴 (2~4명)

세계 22개 도시를 여행하며 땅을 사고 건물을 지어 통행료를 받는 부자 되기 게임입니다.

- 주사위 2개, 더블이면 한 번 더 (세 번 연속이면 🛂 여권 분실)
- 도시를 사면서 🏠 집 → 🏢 빌딩 → 🏨 호텔까지 지을 수 있고, 내 도시에 다시 오면 더 올릴 수 있음
- 🧳 여행 카드 16종, 🎉 세계 축제(통행료 2배), ✈️ 비행기(원하는 칸으로 이동)
- 돈이 모자라면 건물·땅을 반값에 자동으로 팔고, 그래도 모자라면 파산
- 끝내는 방법 선택: 정해진 라운드 / 한 명 파산하면 끝 / 끝까지
- 조작: 주사위는 버튼 또는 `Space`, 카드 확인은 `Enter`, 도시 칸을 클릭하면 자세한 정보
- 📖 도시 도감: 22개 도시의 그림·땅값·주인을 한눈에

**그림과 소리**

- 도시 명소·특수 칸·말·건물은 모두 이 프로젝트에서 직접 그린 SVG 일러스트입니다. (`src/games/world/art/`)
- 배경음악은 직접 작곡한 곡을 WebAudio로 실시간 합성하고(`src/lib/music.ts`, 게임마다 다른 곡), 효과음도 모두 합성음입니다.
  음악과 효과음은 각각 켜고 끌 수 있습니다.
- 3D로 굴러가는 주사위, 칸마다 깡충 뛰는 말, 돈이 오갈 때 떠오르는 숫자, 건물이 올라가는 연출,
  뒤집히는 여행 카드, 차례 알림, 우승 꽃가루 효과가 있습니다. (속도 '아주 빠르게'에서는 일부 생략)

### 한 장 남았다! (2~4명)

같은 색이나 같은 숫자 카드를 내려놓아 손에 든 카드를 먼저 다 내면 이기는 카드 게임입니다.

- 카드 108장: 4색 숫자 카드(0~9), 🚫 건너뛰기, ⇄ 방향 바꾸기, +2, 색 바꾸기, +4
- 카드가 2장일 때 📣 **한 장!** 버튼을 누르고 내야 하고, 깜빡하면 2장을 받음
- **손패 가리기**: 사람이 2명 이상이면 차례마다 "내 카드 보기" 화면이 나와서 서로의 카드를 못 보게 함.
  아이와 규칙을 익힐 때는 **모두 공개**(컴퓨터 카드까지 보임)로 바꿀 수 있음
- 끝내는 방법: **한 판 승부** / **점수 모으기**(200·300·500점, 이긴 사람이 남은 카드 점수를 가져감)
- 조작: 카드는 클릭, 뽑기·넘기기는 `Space`, 색 고르기는 숫자키 `1`~`4`, 카드 보기·다음 판은 `Enter`
- 색마다 모양(빨강 ●, 노랑 ★, 초록 잎, 파랑 ◆)이 있어서 색을 구별하기 어려워도 할 수 있음

| 규칙 (설정에서 켜고 끄기) | 기본 |
| --- | :---: |
| "한 장!" 외치기 (끄면 자동으로 외침) | ✅ |
| +2·+4 누적 (+2 위에 +2·+4, +4 위에 +4를 이어 내서 넘기기) | ❌ |

카드 그림(`src/games/lastcard/CardArt.tsx`)과 카드놀이풍 배경음악은 이 프로젝트에서 직접 만들었습니다.

### 숫자 타일 줄세우기 (2~4명)

같은 색 연속 숫자(빨강 7·8·9)나 같은 숫자 다른 색(5·5·5)으로 줄을 만들어 내 타일을 먼저 다 내면 이기는 타일 게임입니다.

- 타일 106개: 1~13 × 4색 × 2벌 + 조커 2개, 14개씩 시작
- 내 차례: 타일을 눌러 고르고(여러 개 가능) 줄 끝의 **＋**를 누르면 붙이고, **새 줄 만들기**로 새 줄. 끌어다 놓기도 됨
- 판의 모든 줄이 올바르면 **완료**, 낼 게 없으면 **1개 가져오기**. 올바르지 않은 줄은 빨간 테두리와 이유가 바로 보임
- **정통 규칙**: 판 위의 타일을 뜯어서 다시 조합 / **간단 규칙**(어린이용): 새 줄 만들기와 붙이기만
- 조커는 아무 타일이나 대신하고, 판 위에서는 대신하는 숫자를 작게 보여 줌
- 타일 가리기·모두 공개, 정렬(색깔순 7·8·9 / 숫자순 7·7·7)
- 끝내는 방법: **한 판 승부** / **여러 판**(2·3·5판, 점수 합계)
- 컴퓨터(보통)는 긴 줄 나눠 끼우기, 판의 남는 타일 빌려 오기까지 함
- 조작: `Enter` 완료·타일 보기, `Esc` 고른 것 취소, `N` 새 줄

| 규칙 (설정에서 켜고 끄기) | 기본 |
| --- | :---: |
| 판 재배치 (정통 규칙) | ✅ |
| 첫 등록 30점 (처음엔 내 타일로만 합 30 이상) | ✅ |
| 차례 시간 제한 1분·2분 (끝나면 올바른 판은 완료, 아니면 되돌리고 1개 가져오기) | ❌ |

타일 그림(`src/games/tiles/TileArt.tsx`)과 퍼즐풍 배경음악은 이 프로젝트에서 직접 만들었습니다.

### 짝 맞추기 (2~4명)

뒤집힌 그림 카드를 두 장씩 뒤집어 같은 그림을 찾는 기억력 게임입니다.

- 판 크기 4×4(8짝)·4×6(12짝)·6×6(18짝), 그림 카드 동물·과일·채소·탈것 각 18가지 + 골고루 섞기
- 그림 아래에 "토끼", "사과"처럼 이름이 있어서 글자를 익히기에도 좋음
- 컴퓨터도 공개된 카드만 기억함 (쉬움은 금방 잊고, 보통은 꽤 잘 기억함)
- 3D로 뒤집히는 카드, 맞힌 짝은 내 자리로 날아가고, 틀리면 살짝 흔들림
- 조작: 카드는 클릭, 또는 화살표 키로 고르고 `Enter`·`Space`로 뒤집기

| 규칙 (설정에서 켜고 끄기) | 기본 |
| --- | :---: |
| 맞히면 한 번 더 | ✅ |
| 처음에 잠깐 모두 보여 주기 (어린아이용) | ❌ |
| 카드에 이름 쓰기 | ✅ |

카드 그림 54가지(`src/games/memory/CardArt.tsx`)와 통통 튀는 배경음악은 이 프로젝트에서 직접 만들었습니다.

### 도둑잡기 (2~4명)

옆 사람 카드를 한 장씩 뽑아 같은 숫자 두 장을 버리고, 마지막까지 조커(도둑)를 든 사람이 지는 카드 게임입니다.

- 카드 52장 + 조커, 처음 짝은 저절로 버림
- 다음 사람 뒷면 카드에 마우스를 올리면 들리고, 누르면 두근두근 뒤집힘
- 🔀 섞기로 조커 숨기기 (컴퓨터는 뽑을 때마다 섞음)
- 손패 가리기 / 모두 공개(배우기용)
- 컴퓨터(보통)는 몰래 보지 않고, 본 것만 기억함
- 조작: 카드 클릭, ←→ 고르기 후 `Space`·`Enter`, 숫자키 `1`~`9`, `S` 섞기

카드 그림(`src/components/PlayingCard.tsx`: 무늬 배치, 만화풍 J·Q·K, 복면 도둑 조커)과 살금살금 피치카토풍 배경음악은 직접 만들었습니다.

### 칠 이어놓기 (2~4명)

7을 가운데 놓고 같은 무늬로 위아래 숫자를 이어 내서 손패를 먼저 다 내면 이기는 카드 게임입니다.

- ♦7을 가진 사람이 저절로 시작, 낼 수 있으면 꼭 내야 함
- 내 카드를 놓을 수 있는 판의 빈칸이 반짝임
- 끝내는 방법: 한 판(순위) / 점수 모으기(100·200·300점)
- 조작: ←→ 고르기, `Enter`·`Space` 내기, 낼 카드가 없으면 `Space` 통과

| 규칙 (설정에서 켜고 끄기) | 기본 |
| --- | :---: |
| 통과 3번 제한 (4번째엔 탈락, 카드를 판 제자리에 내려놓음) | ✅ |

느긋한 스윙풍 배경음악은 직접 작곡했습니다.

### 도미노 (2~4명)

끝 숫자가 같은 패를 이어 붙여 내 패를 먼저 다 내면 이기는 패 잇기 게임입니다.

- 더블식스 패 28개: 2명이면 7개씩, 3~4명이면 5개씩, 남은 패는 뽑는 더미
- 첫 판은 가장 높은 더블을 가진 사람이 자동으로 놓고 시작 (더블이 없으면 점이 가장 많은 패)
- 두 끝에 다 맞으면 어느 끝에 놓을지 고르기 (두 자리가 반짝이고 미리 보기가 보임)
- 낼 패가 없으면 낼 수 있을 때까지 뽑고, 더미가 비면 통과. 줄이 길어지면 탁자 끝에서 꺾여 뱀처럼 이어짐
- 이긴 사람은 다른 사람들 손에 남은 점을 모두 가져감. 막히면 남은 점이 가장 적은 사람이 승리
- 손패 가리기(차례 넘김 화면) / 모두 공개(배우기용), 숫자마다 점 색이 다른 "점 색깔"
- 끝내는 방법: 한 판 승부 / 점수 모으기(50·100·150점)
- 컴퓨터(보통)는 무거운 패·더블 먼저, 이어 낼 끝 남기기, 상대가 뽑거나 통과할 때 없던 숫자로 막기
- 조작: 패는 클릭 또는 ←/→·숫자키 후 `Enter`, 끝 고르기 ←/→, 뽑기 `D`, 통과 `Space`

| 규칙 (설정에서 켜고 끄기) | 기본 |
| --- | :---: |
| 블록 규칙 (낼 패가 없으면 뽑지 않고 통과) | ❌ |
| 이긴 사람이 다음 판 시작 (아무 패나) | ✅ |
| 점 색깔 (숫자마다 다른 색) | ❌ |

패 그림(`src/games/domino/DominoArt.tsx`)과 카페풍 라틴 배경음악은 이 프로젝트에서 직접 만들었습니다.

### 거짓말쟁이 (2~4명)

A, 2, 3 … K 순서대로 그 숫자라고 말하며 카드를 뒷면으로 내고, 거짓말 같으면 "거짓말이야!"를 외치는 속이기 카드 게임입니다.

- 내 차례에 카드 1~4장을 골라 "7 두 장!"처럼 지금 숫자라고 말하며 내기. 그 숫자가 없으면 다른 카드로 거짓말
- 의심하면 카드를 뒤집어서(✓/✗) 거짓말이면 낸 사람이, 진짜면 외친 사람이 가운데 더미를 모두 가져감
- 손패를 먼저 다 내면 우승. 단, 마지막 카드가 거짓말로 들키면 더미를 가져가고 계속
- 나눠 주는 장수: 2명 18장(16장은 아무도 모르게 빼 둠)·3명 17장·4명 13장, 빨리 하기는 10·9·8장
- 의심 칸에 내 손의 그 숫자 장수를 보여 주고, 같은 숫자가 4장을 넘으면 "확실한 거짓말"이라고 알려 줌
- 손패 칸에 앞으로 내 차례마다 낼 숫자(예: 4 → 8 → Q)를 보여 줘서 아껴 둘 카드를 정하기 쉬움
- 컴퓨터는 남의 카드를 몰래 보지 않음. 쉬움은 가끔 아무 때나 의심하고, 보통은 자기 카드와 자기가 낸 카드로 확실한 거짓말을 잡고 진짜일 확률을 어림해서 의심, 곧 쓸 숫자는 아끼고 필요 없는 카드로 거짓말
- 손패 가리기(차례 넘김 화면) / 모두 공개(배우기용), 끝나면 순위와 거짓말·의심 기록, 명탐정·포커페이스 별명
- 조작: 카드 클릭 또는 ←→ + `Space`로 고르기, `A` 지금 숫자 모두 고르기, `Enter` 내기, 거짓말! `D`, 믿어요 `Space`

### 말랑 팡팡 (1~2명)

두 개씩 떨어지는 젤리를 돌리고 옮겨서 같은 색 4개를 이으면 팡! 터진 자리에 떨어진 젤리가 또 이어지면 연쇄가 되는 실시간 퍼즐입니다.

- **대결**: 자리마다 **사람 / 컴퓨터(쉬움·보통·어려움)**. 사람 둘이면 한 키보드로 동시에(왼쪽 WASD, 오른쪽 방향키), 컴퓨터끼리 구경도 가능
- **혼자 하기**: 끝없이 쌓으며 점수 도전, 많이 터뜨릴수록 레벨이 올라 빨라짐
- 점수 = 10 × 터진 수 × (연쇄 + 여러 색 + 큰 덩어리 보너스), 판을 모두 비우면 보너스
- 대결에서는 점수만큼 상대에게 회색 방해 젤리를 보내고, 나에게 올 방해 젤리는 내 연쇄로 먼저 막기(상쇄). 한 번에 최대 30개, 오래 하면 방해 젤리가 점점 쉽게 만들어짐
- 왼쪽에서 세 번째 줄 맨 위(✕)까지 차면 짐. 위험하면 ✕가 깜빡이고 젤리들이 겁먹은 표정
- 다음 조각 2개 미리 보기, 방해 젤리 예고(작은 젤리 1 · 큰 젤리 6 · 구름 30), 떨어질 자리 미리 보기
- 두 사람은 같은 순서로 조각을 받음 (공평하게)
- 컴퓨터는 상대 판을 보지 않고, 갈 수 있는 모든 자리를 놓아 보며 연쇄와 '연쇄 씨앗'(젤리 한두 개만 더 오면 몇 연쇄가 될지)을 따짐. 쉬움은 보이면 바로 터뜨리고, 보통은 2연쇄부터, 어려움은 다음 조각까지 보고 4연쇄 이상을 모아 쏨
- 3·2·1로 시작, `P`·`Esc`로 멈추기, 다른 창으로 가면 저절로 멈춤. 하던 판은 저장되어 멈춘 채로 이어 할 수 있음
- 터치 화면에서는 화면 단추(◀ ⟲ ▼ ⤓ ⟳ ▶)
- 기록: 혼자 하기 최고 점수, 가장 긴 연쇄, 컴퓨터를 이긴 횟수

### 점과 상자 (2~4명)

점 사이에 선을 하나씩 그어 네 번째 선으로 상자를 완성하면 내 것이 되고 한 번 더! 상자를 가장 많이 모으면 이기는 종이·연필 놀이입니다.

- 자리마다 **사람 / 컴퓨터(쉬움·보통) / 비움** 선택, 판 크기 3×3~6×6 (2명 4×4, 3~4명 5×5 추천)

- 컴퓨터(보통)는 사슬·고리를 읽고 끝판에는 마지막 두 상자를 남겨 주는 "더블 크로스"로 주도권을 지킴
- 조작: 점 사이 아무 데나 클릭(가장 가까운 선), 또는 화살표 키로 고르고 `Enter`/`Space`로 긋기

숨긴 숫자를 스트라이크·볼 힌트로 추리해서 맞히는 종이·연필 놀이입니다. 숫자와 자리가 맞으면 스트라이크, 숫자만 맞으면 볼, 하나도 없으면 아웃!

- **둘이서 대결**: 서로 비밀 숫자를 숨기고 번갈아 치기(1회초·1회말 …). 자리마다 **사람 / 컴퓨터(쉬움·보통·어려움)**
- **혼자 맞히기**: 컴퓨터가 숨긴 숫자를 몇 번 만에 맞히는지 도전, 설정마다 최고 기록 저장, 답 보기
- 3자리 / 4자리, 1~9 또는 0~9, 같은 숫자는 한 번만
- 야구장 전광판: 친 숫자와 스트라이크(노랑)·볼(초록) 불, 공이 날아와 딱! 맞는 연출, 홈런·마지막 기회 알림
- 📝 메모: 숫자마다 ○(있다) / ✕(없다), 메모한 숫자는 숫자 단추에도 표시
- 🔎 추리 도우미: 답일 수 있는 숫자가 몇 개 남았는지(12개 이하면 목록 보기), 넣은 숫자가 앞 결과와 맞지 않으면 알림, 아웃·홈런 숫자 자동 메모
- 사람 둘이면 비밀 숫자를 정할 때만 차례 넘김 화면, 내 숫자는 꾹 눌러서 보기. 친 숫자와 결과는 모두가 함께 봄
- 컴퓨터는 상대 숫자를 보지 않고 자기 결과만 씀: 쉬움(최근 결과 2개만 기억), 보통(3개 기억), 어려움(후보를 가장 고르게 나누는 숫자). 3자리 1~9에서 평균 약 7.8번 / 5.6번 / 4.8번 만에 맞힘
- 조작: 숫자 단추 또는 키보드 숫자, `Backspace` 지우기, `Esc` 모두 지우기, `Enter` 치기, `Shift`+숫자 메모

| 규칙 (설정에서 켜고 끄기) | 기본 |
| --- | :---: |
| 0도 쓰기 (끄면 1~9만) | ❌ |
| 마지막 기회 (먼저 친 편이 맞혀도 나중 편에게 한 번 더, 둘 다 맞히면 무승부) | ✅ |
| 추리 도우미 | ✅ |

전광판·야구 모자·공 그림과 야구장 오르간풍 배경음악은 이 프로젝트에서 직접 만들었습니다.

### 스도쿠 (1명)

가로줄·세로줄·3×3 칸마다 1~9를 한 번씩 채우는 숫자 퍼즐입니다. 화면에서 풀거나 A4 문제지로 인쇄해서 풀어요.

- 문제는 그때그때 새로 만들고(해답이 하나뿐인지 확인), 사람이 푸는 방법으로 난이도를 매김
- 모든 문제에 **문제 번호**(예: `2-04821`)가 있어서 번호를 넣으면 같은 문제가 나옴
- 메모(후보 숫자), 숫자를 넣으면 메모 저절로 지우기, 후보 숫자 모두 채우기, 겹침·틀림 표시
- 💡 힌트: "이 칸에는 7만 들어갈 수 있어요"처럼 찾는 방법을 알려 주며 한 칸 채우기
- 되돌리기·다시 하기, 잠깐 쉬기, 시계, 난이도별 최고 기록
- 🖨 **문제지 인쇄**: 난이도(섞어서), 한 쪽에 1·2·4·6문제, 1~20쪽, 맨 뒤 정답지, 이름·날짜 칸, 미리보기
- 조작: 클릭·화살표, 숫자 `1`~`9`, 지우기 `Backspace`·`0`, 메모 `N`·`Shift`+숫자, 힌트 `H`, `Ctrl+Z`/`Ctrl+Y`, 쉬기 `P`

| 난이도 | 처음 숫자 | 필요한 방법 |
| --- | :---: | --- |
| 쉬움 | 36~40개 | 하나만 남은 칸, 여기밖에 없는 칸 |
| 보통 | 26~32개 | + 가리키기·가두기, 두 칸 두 숫자 |
| 어려움 | 22~29개 | + 숨은 짝, X-윙, XY-윙 |
| 아주 어려움 | 20~27개 | 더 어려운 방법이 필요 |

| 규칙 (설정에서 고르기) | 기본 |
| --- | :---: |
| 틀린 숫자 바로 표시 (끄면 다 채운 뒤 확인) | ✅ |

판·문제지 그림과 차분한 배경음악(라장조, 88 BPM)은 이 프로젝트에서 직접 만들었습니다.

## 자동 빌드와 배포

`.github/workflows/build.yml`이 push할 때마다 실행됩니다.

1. **모든 브랜치·PR**: 타입 검사 → 테스트 → 빌드 → zip을 Actions 아티팩트로 보관
2. **기본 브랜치에 push**:
   - [Releases](https://github.com/lengbong/BoardGame/releases)의 `최신 빌드`(태그 `latest`)를 새 zip으로 교체
   - GitHub Pages에 배포
3. **`v*` 태그 push** (예: `v1.0.0`): 그 버전의 릴리스를 따로 만들어 보관

> Pages 배포는 저장소 **Settings → Pages → Source**가 **GitHub Actions**로 되어 있어야 동작합니다. (설정 완료됨)

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install
```

```bash
npm run dev        # 개발 서버 (http://localhost:5173)
```

```bash
npm test           # 규칙·컴퓨터 플레이어 테스트
```

```bash
npm run build      # dist/index.html 한 파일로 빌드
```

빌드 결과는 JS·CSS가 모두 들어간 `dist/index.html` 한 파일이라서 `file://`로 열어도 실행됩니다.

### 구조

```
src/
  App.tsx                 처음 화면 (분류별 게임 선택)
  games/registry.ts       게임 목록과 분류 — 새 게임은 여기에 추가
  games/guides.ts         게임마다 처음 하는 사람 안내 3장
  sim/                    컴퓨터끼리 여러 판 돌려 실력 순서를 확인하는 테스트
  games/common/           여러 게임이 함께 쓰는 정의
    players.ts            4인 자리 (사람·컴퓨터·비움, 자리 색)
    duel.ts               2인 자리 (컴퓨터 쉬움·보통·어려움)
    settings.ts           게임별 속도·효과음·음악 설정
    playingCards.ts       트럼프 카드 52장 + 조커 (도둑잡기, 칠 이어놓기, 거짓말쟁이)
  games/race/             말판 경주
    rules.ts              규칙 (순수 함수, UI와 분리)
    ai.ts                 컴퓨터 플레이어
    board.ts              판 좌표
    RaceGame.tsx …        화면
  games/world/            지구 한 바퀴 (같은 구조, art/ 에 일러스트)
  games/lastcard/         한 장 남았다! (같은 구조, CardArt.tsx 에 카드 그림)
  games/tiles/            숫자 타일 줄세우기 (sets.ts 줄 검사, work.ts 차례 중 판 고치기)
  games/memory/           짝 맞추기 (themes.ts 그림 묶음, CardArt.tsx 그림 54가지)
  games/oldmaid/          도둑잡기
  games/sevens/           칠 이어놓기
  games/domino/           도미노 (layout.ts 뱀처럼 꺾이는 줄 배치)
  games/reversi/          뒤집기
  games/fourline/         사목
  games/mancala/          만칼라 (animation.ts 씨앗 뿌리기 연출 순서)
  games/boxes/            점과 상자
  games/ships/            배 찾기 (fleet.ts 함대와 배 놓기)
  games/omok/             오목 (rules.ts 다섯·금수 판정, ai.ts 연속 사를 찾는 컴퓨터)
  games/malang/           말랑 팡팡 (engine.ts 실시간 엔진, ai.ts 연쇄 씨앗을 따지는 컴퓨터, Board.tsx 판 그림)
  games/baseball/         숫자야구 (Scoreboard.tsx 전광판, BatBox.tsx 숫자 칸·단추·메모)
  games/cheat/            거짓말쟁이 (ai.ts 진짜일 확률 어림하기)
  games/sudoku/           스도쿠 (generator.ts 문제 생성, logic.ts 사람식 풀이·난이도, Print*.tsx 인쇄)
    (게임마다 song.ts 배경음악, sounds.ts 효과음)
  components/             공용 화면 조각 (주사위, 3D 주사위, 자리 선택, 2인 자리 선택,
                          차례 넘김 화면, 패널 버튼 줄, 트럼프 카드 그림, 꽃가루, 색 모양)
  lib/                    공용 도구 (저장, 효과음, 배경음악, 타이머, 난수, 조사 붙이기, 주소(#/게임) 기억, 맨 위로 올리기)
```

새 게임 추가: `src/games/<게임>/`에 컴포넌트를 만들고 `src/games/registry.ts`의 `GAMES`에 분류(`category`)와 함께 등록하면 처음 화면에 나타납니다.
